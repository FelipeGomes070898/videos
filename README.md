# videos

Padrão e código dos documentários animados 2D verticais.

- `BRIEF.md`: padrão visual, técnico e de áudio.
- `HANDOFF.md`: estado atual e próximo passo.
- `engine/`: motor de animação 2.5D.
- `scenes/`: roteiro e parâmetros por vídeo.
- `thumbs/`: miniaturas.

Para continuar num chat novo: "Leia BRIEF.md e HANDOFF.md e continue: <tarefa>".
